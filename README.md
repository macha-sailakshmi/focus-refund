# focus-refund
A productivity web app project

**Live**: https://cute-nougat-36d002.netlify.app

**Tech Stack**: HTML, CSS, JavaScript

## How it works
1. Set your age to get tasks
2. Earn coins by completing real-world tasks
3. Spend coins to unlock social media for limited time

## Features
- Responsive design for mobile + desktop
- Glassmorphism UI
- LocalStorage to save progress
